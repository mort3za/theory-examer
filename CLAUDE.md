# Theory Examer

Personal web app to learn the German driving theory exam (class B, English questions, optional German text). Single user, no backend. Static build, deployable to GitHub Pages.

## Stack

- Vue 3 (`<script setup lang="ts">`), Pinia, vue-router (hash history)
- Vite (run through Bun), Tailwind CSS v4, shadcn-vue (Reka UI) in `src/components/ui/`
- Icons: `@lucide/vue`. Toasts: `vue-sonner` (`import { toast } from "vue-sonner"`)
- Spaced repetition: `ts-fsrs` (FSRS), wrapped in `src/lib/srs.ts`
- Storage: IndexedDB via `idb-keyval` (progress), localStorage (settings)
- PWA: `vite-plugin-pwa`

## Commands

- `bun install` – install
- `bun run dev` – dev server
- `bun test` – unit tests (`src/lib/*.test.ts`, `bun:test`)
- `bun run typecheck` – `vue-tsc -b` (must be clean)
- `bun run build` – type check + production build to `dist/`
- `bun run data` – re-download the question catalogue into `public/data/`

## Layout

- `src/lib/` – pure logic, no Vue. Every module here has a `*.test.ts`. Put new non-trivial logic here (testable), not in components.
  - `types.ts` catalogue types · `answer.ts` correctness · `exam.ts` exam rules/scoring · `srs.ts` FSRS wrapper · `queue.ts` session queue · `review.ts` daily plan + forecast · `practice.ts` practice selection · `date.ts` study day (starts 04:00) · `random.ts`
- `src/stores/` – `catalog` (questions, themes, chapters, German texts), `settings`, `progress` (cards, stats, flags, notes, hidden, log, exams; saved to IndexedDB)
- `src/components/` – app components; `ui/` is generated by shadcn-vue (add with `bunx shadcn-vue@latest add <name>`, then replace `from 'cn'` imports with `from '@/lib/utils'`)
- `src/views/` – one file per route (see `src/router.ts`)

## Domain rules

- A multiple-choice answer is correct only when the exact set of correct options is selected.
- Exam (class B): 20 basic (theme 1.x) + 10 class questions (2.x), 45 min, pass ≤ 10 error points, but two wrong 5-point questions = fail. Videos: max 5 plays in the exam.
- Review: wrong answer → FSRS "Again" automatically; correct → user picks Hard/Good/Easy (default Good).
- Practice and exam answers always update stats. Practice also grades FSRS only when the card is new or due (`progress.isScheduling`). Exam never grades FSRS.
- `progress.pool` = questions in enabled chapters and not hidden. Use it for every study list.

## UI rules (keep it minimal and professional)

- Neutral zinc palette. Primary = foreground color (near black / near white). Semantic colors only from tokens: `success`, `destructive`, `warning`, `info` (e.g. `text-success`, `bg-success/10`). No gradients, no decorative colors, no emoji.
- Use shadcn-vue components from `@/components/ui/*`. Borders `border rounded-lg`, no shadows except floating bars/menus.
- Page header: `<h1 class="text-2xl font-semibold tracking-tight">` + one `text-sm text-muted-foreground` line. Section label: `text-sm font-medium text-muted-foreground`.
- Numbers: `tabular-nums`. Icons: `size-4`/`size-5`, `text-muted-foreground` when decorative.
- Mobile first (phone is a main device). Normal pages sit in the AppShell (`max-w-5xl`); focus pages (`meta.focus`) have their own full-screen layout. The mobile tab bar is 4rem high: fixed bottom elements must sit above it.
- Light and dark mode must both work (only use tokens, never raw `zinc-*`/`white`).
- Short, plain English copy.
